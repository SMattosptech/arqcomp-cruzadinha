# Desafio da Arquitetura — Cruzadinha

Jogo de cruzadinha para praticar conceitos de Arquitetura Computacional.

## Como jogar
1. Abra `index.html` no navegador ou acesse o site publicado.
2. Escolha uma pista pelos botões numerados (H = horizontal; V = vertical). A pista completa aparece em destaque.
3. Digite uma letra em cada casa do tabuleiro. As setas do teclado também ajudam na navegação.
4. Clique em **Conferir palavra** para verificar somente a palavra selecionada.
5. Se errar, a resposta não é mostrada: corrija as letras e clique novamente em **Conferir palavra**.
6. Use **Conferir todas** para verificar o tabuleiro inteiro ou **Reiniciar** para começar novamente.

## Palavras utilizadas e pistas

| Palavra | Pista |
|---|---|
| DUALCORE | Processador que possui dois núcleos de execução. |
| FLASH | Memória não volátil que pode ser apagada e regravada eletricamente. |
| UC | Coordena e controla a execução das instruções dentro do processador. |
| DMA | Permite transferir dados entre memória e periféricos sem intervenção contínua do processador. |
| CACHE | Memória pequena e rápida que mantém cópias de dados frequentemente acessados. |
| CPU | Componente que interpreta e executa instruções de programas. |
| EEPROM | Memória não volátil que permite apagar e gravar bytes eletricamente. |
| DATABUS | Caminho que transporta informações entre componentes do computador. |
| ULA | Bloco responsável por cálculos matemáticos e comparações lógicas. |
| ROM | Armazena instruções permanentes necessárias à inicialização do sistema. |
| REGISTRADORES | Pequenas posições internas que guardam temporariamente valores usados pelo processador. |
| RAM | Guarda temporariamente programas e dados em uso; perde conteúdo sem energia. |
